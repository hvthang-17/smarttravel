# SmartTravel Agent Guide & Skill Definition

Use this skill configuration when building or editing features in SmartTravel.

## Feature Creation Checklist
- [ ] Backend: Entity, DTO, Repository, Service, Controller, Flyway migration
- [ ] Backend: Standard response envelope `ApiResponse<T>` used
- [ ] Mobile: Model, Repository, Riverpod Provider, Screen, GoRouter route
- [ ] Admin: TypeScript types, API client service, React view component
- [ ] Validation: `mvn test`, `flutter analyze`, `npm run build` executed and passed
